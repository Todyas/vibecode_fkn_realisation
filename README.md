## 🚀 Продукт: «no idea» (Командный второй мозг в Telegram)

> **Проблема:** Команда обсуждает идею в десятках хаотичных сообщений в рабочем Telegram-чате. Через час никто не помнит, на чем сошлись, а выпавшему участнику приходится читать всю переписку. Отдельные внешние сервисы открывать неудобно — команда уже общается в Telegram.  
> **Решение:** Telegram-бот `/no_idea`, который сидит в рабочем чате команды и на лету превращает обсуждение в структурированный живой канвас на веб-сайте:
> - Команда `/no_idea start <Тема>` — бот начинает слушать сообщения и присылает ссылку на канвас;
> - В процессе: бот извлекает тезисы, раскладывает по 7 блокам, сжимает повторы и задает вопросы реплаем только при реальных конфликтах;
> - Команда `/no_idea stop` — бот закрывает тему и выгружает в чат PNG-картинку канваса, 5-строчное саммари и Markdown-файл.

### 🧠 Ключевая логика агента:
1. **Одна цель, разные формулировки:** агент объединяет схожие идеи разных участников в один тезис (сверху общая цель, снизу детали и аватары авторов).
2. **Настоящий конфликт интересов:** агент не склеивает противоречия, а помечает красным ребром на канвасе и задает уточняющий вопрос реплаем в чат.
3. **Анализ последствий (Impact):** при изменении ограничений подсвечивает зависящие от них тезисы (`needs_review`).
4. **Вопросы боту по канвасу:** команда `/no_idea ask <вопрос>` отвечает на факты из истории обсуждения.

### 🖥️ Структура живого канваса (7 блоков):
- 🎯 **Суть (`essence`):** одна главная фраза о текущей задаче;
- 🛑 **Проблема (`problem`):** исходная боль и причины обсуждения;
- 👥 **Для кого (`audience`):** целевая аудитория и сегменты;
- 💡 **Решение (`solution`):** предложения и идеи (с иерархией деталей и канонизацией целей);
- 🔒 **Ограничения (`constraints`):** бюджет, сроки, стек, ресурсы;
- ⚠️ **Риски (`risks`):** возможные угрозы и опасения;
- ❓ **Открытые вопросы (`questions`):** неразрешенные вопросы и маркеры конфликтов.

## 🛠 Технологический стек и архитектура

- **Telegram Bot:** `aiogram` 3.x (long polling, обработка команд `/no_idea start`, `/no_idea stop`, `/no_idea ask`, сбор сообщений).
- **Web Canvas (Frontend):** React / Vite + Tailwind CSS (живое дерево карточек канваса, статусы `new`, `active`, `disputed`, `needs_review`).
- **Backend / Reducer:** Python (FastAPI / WebSocket) + детерминированный Reducer (валидация Pydantic v2, закрытый список Patch-операций).
- **ML / AI пайплайн:** Двухконтурный — быстрый Extractor (Haiku / mini модели через OpenRouter) и глубокий Mediator (Sonnet / pro модели).
- **Экспорт:** Playwright для генерации PNG-снапшота канваса + Markdown саммари.

## 🎯 Выбранная тема проекта

Команда официально участвует в **Теме 3: «Второй мозг»**:
> **Тема 3: «Второй мозг»** — инструмент, который помогает человеку или команде сохранять, связывать и использовать информацию из своей жизни, работы или учебы. Решение накапливает контекст и помогает применить его в нужный момент.
> 
> *Наше позиционирование:* **«Командный второй мозг»** — сервис, который извлекает контекст из хаотичной командной переписки (чат Telegram), распознает мотивы участников, находит скрытые противоречия и на лету кристаллизует их в согласованную живую доску решений.
