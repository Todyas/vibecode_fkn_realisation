## 🚀 Проект: «Общий знаменатель» (Командный второй мозг)

> **Проблема:** Команда обсуждает задачу в десятках хаотичных сообщений, каждый участник тянет в свою сторону, но общее понимание и согласованное решение так и не появляются.  
> **Решение:** Сервис с разделенным экраном (Split View):
> - **Слева (Чат):** командный чат (аналог Telegram), куда участники (разработчик, дизайнер, маркетолог, PM, руководитель) пишут идеи, требования и возражения.
> - **Справа (Живая доска):** структурированная, конечная доска решения, которая обновляется на лету на основе контекста обсуждения.

### 🧠 Ключевая фишка агента (из техдока):
Агент не склеивает всё подряд, а различает две принципиальные ситуации:
1. **Одна цель, разные способы:** агент предлагает общий вариант решения.
2. **Настоящий конфликт интересов:** агент не объединяет, а прямо спрашивает команду, что приоритетнее, и показывает, чем жертвует каждый вариант.
3. **Анализ последствий (Impact):** при смене ограничений подсвечивает красным (`needs_review`) зависящие от них решения.

### 🖥️ Структура интерфейса (Split View):
- **Левая панель (35%): Командный чат**
  - Лента сообщений с ролями/авторами;
  - Поле ввода реплик;
  - Реплики и вопросы от AI-фасилитатора.
- **Правая панель (65%): Живая доска решения**
  - 🎯 **Блок 1: Цель задачи** (сформулированная и согласованная цель);
  - ⚡ **Блок 2: Выявленные противоречия и ограничения** (подсветка конфликтующих требований);
  - 📋 **Блок 3: Согласованное решение / План шагов** (кристаллизованный план);
  - ❓ **Блок 4: Открытые вопросы и следующие шаги**;
  - 💡 **Блок 5: Предложение агента** (компромиссный вариант для утверждения командой).

## 🛠 Технологический стек и архитектура

- **Frontend:** React / Vite + Tailwind CSS (Split view, Telegram-like chat, реактивный рендеринг карточек доски по JSON-состоянию).
- **Backend / AI:** Python (FastAPI) или Node.js + Structured Outputs LLM API (Claude 3.5 Sonnet / GPT-4o / Llama 3) с жесткой JSON-схемой состояния доски.
- **Интеграция:** REST / WebSocket эндпоинт `/api/chat/message`, принимающий сообщение и возвращающий обновленную схему доски и ответ агента.

## 🎯 Выбранная тема проекта

Команда официально участвует в **Теме 3: «Второй мозг»**:
> **Тема 3: «Второй мозг»** — инструмент, который помогает человеку или команде сохранять, связывать и использовать информацию из своей жизни, работы или учебы. Решение накапливает контекст и помогает применить его в нужный момент.
> 
> *Наше позиционирование:* **«Командный второй мозг»** — сервис, который извлекает контекст из хаотичной командной переписки (чат Telegram), распознает мотивы участников, находит скрытые противоречия и на лету кристаллизует их в согласованную живую доску решений.

## 📊 Официальные критерии оценивания

Оценка выставляется по шкале 0–10 с умножением на весовой коэффициент:

| Критерий | Вес / Фокус | Описание |
| :--- | :---: | :--- |
| **Оригинальность** | **25% (Высший вес)** | Новизна, неожиданность, интересная идея, непохожесть на решения других команд. Главный фильтр в топ-10. |
| **Польза** | Значимость | Практическая или социальная значимость, решение конкретной проблемы понятной целевой аудитории. |
| **Работоспособность** | Демо MVP | Соответствие MVP заявленной функциональности, стабильная работа прототипа на живой демонстрации. |
| **Качество исполнения** | Технологии & Питч | Качество написания кода и архитектуры + убедительность и качество подготовки презентации и защиты. |
| **Работа в команде** | Зоны ответственности | Четкое распределение ролей, слаженность и вклад каждого участника в результат. |
| **Использование ИИ** | Агенты & Пайплайны | Глубина автоматизации с помощью нейросетей, агентные подходы, пайплайны, системная AI Engineering Strategy. |
