# Вайбкодинг ФКН (VibeHack)

2. **Шаг 2:** Выбрать технологии и AI-инструменты (выполняется разработчиками по факту).
3. **Шаг 3:** Распределить задачи внутри команды.
4. **Шаг 4:** Собрать работающий MVP.
5. **Шаг 5:** Проверить основные пользовательские сценарии.

## 🤖 AI Engineering Strategy

Согласно регламенту хакатона, **AI Engineering Strategy** — одна из ключевых составляющих проекта. Оценивается не просто число обращений к AI, а осмысленность и воспроизводимость командного процесса.

Вся документация по использованию AI фиксируется в файле [AI_ENGINEERING_STRATEGY.md](AI_ENGINEERING_STRATEGY.md):
- Какие AI-инструменты применялись и для каких задач
- Как передавался контекст моделям
- Как участники разделили работу между собой и AI
- Как проверялись сгенерированный код, данные и выводы
- Где AI оказался полезен, а где потребовалось вмешательство человека
- Как менялся процесс после ошибок и неудачных попыток
