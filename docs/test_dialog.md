# Тестовый диалог для Telegram (один человек играет всю команду)

Каждое сообщение отправляй отдельно, пауза 4–5 секунд. Префикс «Роль:» бот считает автором (ROLEPLAY_NAMES=1).

```
/no_idea start Продажи
```
1. `Руководитель: Хотим поднять продажи на 15% за квартал, большого бюджета нет`
2. `Маркетолог: Люди уходят без покупки, нужны персональные предложения`
3. `Дизайнер: Давайте сократим путь до покупки, сейчас 5 шагов оформления` — ждём слияние в «одну цель», тост на сайте, бот молчит
4. `Разработчик: Сложные рекомендации не потянем, нас двое и месяц` — ограничение, возможно одна фраза бота
5. `Маркетолог: И нужна рассылка со скидкой 20% всем, чтобы вернуть старых клиентов` — конфликт, бот спрашивает реплаем
6. **Реплаем на вопрос бота:** `Руководитель: Маржа важнее. Скидка максимум 5% и только на наборы` — рассылка зачёркнута
7. `Руководитель: Новости: бюджет дали, но срок — 2 недели вместо месяца` — карточки желтеют, бот пишет, что пересмотреть
8. `Дизайнер: Да, сначала оформление, наборы вторым этапом`

```
/no_idea ask Продажи что решили по скидке?
/no_idea export Продажи
/no_idea stop Продажи
/no_idea start Продажи
/no_idea list
```
Последние два: тема переоткрывается с той же ссылкой; list показывает темы.
