# Исходные материалы хакатона (Initial Materials)

В этой папке собрана вся информация, предоставленная организаторами и зафиксированная на старте турнира:

1. **[techdoc_bogdan.pdf](./«Общий%20знаменатель»%20—%20техдок%20для%20хакатона-1.pdf)** — Исходное техническое задание (ТЗ) и архитектурный техдок от Богдана на 29 страниц.
2. **Официальные правила хакатона:**
   - Формат очный, разработка до **17:30** (Стоп-кодинг).
   - В финал на очную защиту выходят **только 10 команд** из всех (~400 человек).
   - Разрешено использовать любые ресурсы и ИИ-инструменты.
3. **Официальные критерии оценивания:**
   - 🥇 **Оригинальность — 25% (Высший вес)**
   - 🎯 **Польза / Значимость**
   - ⚙️ **Работоспособность (демо MVP)**
   - 💻 **Качество исполнения (код + питч)**
   - 🤝 **Работа в команде (распределение ролей)**
   - 🤖 **Использование ИИ (пайплайны, агенты, глубина интеграции)**
4. **Темы турнира:**
   - Тема 1: «Без инструкции»
   - Тема 2: «Интернет больше не доказательство»
   - **Тема 3: «Второй мозг»** — ✅ Выбор команды
   - Тема 4: «Open Source × AI»
5. **Чек-поинты турнира:**
   - Чек-пойнт №1: 13:00 (Название: «no idea», Тема 3) — сдан.
