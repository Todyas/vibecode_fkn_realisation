# Материалы разработки проекта (Project Materials)

В этой папке накапливаются артефакты, создаваемые командой в процессе разработки проекта **«Общий знаменатель»**:

- **[demo_script.md](./demo_script.md)** — Сценарий живой демонстрации из 8 реплик (демонстрирует все 3 типа вмешательства агента: объединение, конфликт, последствия).
- **[data_models.md](./data_models.md)** — Контракты данных, Pydantic-схемы состояния `RoomState` и список операций редьюсера (`patch ops`).
- **Промпты:** спецификации и промпты для `Extractor`, `Mediator`, `Impact` (в `prompts/`).
- **Сценарии тестирования (eval):** наборы `scenarios/*.json` для замера качества агента.
- **Презентация и питч:** структура 3-4 минутного выступления и слайды к защите.
